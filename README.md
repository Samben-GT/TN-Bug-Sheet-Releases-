# TN Bug Sheet - app downloads

Android app for reporting civic problems in Tamil Nadu. This repo only holds the APK builds. The code is private.

## Install with automatic updates (Obtainium)

1. Install Obtainium: https://github.com/ImranR98/Obtainium/releases (pick the `app-arm64-v8a-release.apk` file).
2. In Obtainium tap **Add App** and paste: `https://github.com/Samben-GT/TN-Bug-Sheet-Releases-`
3. Tap **Add**, then **Install**. Obtainium checks for new builds and updates the app.

Or download the latest APK directly from **Releases** on this page.

Signing in needs an account from Sam. Reports are visible only to you and the admins.
